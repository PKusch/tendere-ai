# Security

Tendere AI works with people's skills and work history, so the bugs that matter most are ones that show someone data they should not see, or that let the page or the engine be fed content that changes what it does. Please report those. Wrong rankings or gaps in the data are normal issues.

## How to report

Use GitHub's private report: open the **Security** tab of this repository and choose **Report a vulnerability**. Please do not open a public issue for it until it is fixed.

## What to expect

This is a one-person project, so there is no formal response time. A report that comes with steps to reproduce it gets read promptly.

## Supported versions

Only the latest commit on `main` is supported.
